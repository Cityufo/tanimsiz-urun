# Tanımsız Ürün Kartı (pilot)

City Lojistik Kayıp Birimi tanımsız ürün etiketlerindeki QR kodun açtığı sayfa.

- `index.html` – kart sayfası. Adres: `https://yildirim-ux.github.io/tanimsiz-urun/#DOSYA-NO`
- `data.json` – dosya listesi (dosya no, rapor, kayıt tarihi, ürün, yer, durum, sonuç tarihi, arşiv bağlantısı). Her iş günü sabahı MASTER Tanımsız Ürün Takip raporundan güncellenir.

Gönderici, alıcı, sevkiyat numarası ve açıklama bilerek yayınlanmaz.
